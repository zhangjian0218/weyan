# 微言（WeYan）—— 简单本地化内容社区

一个使用纯 HTML + CSS + JavaScript 实现的极简社交内容发布应用（不含任何第三方框架与后端），数据通过浏览器 Local Storage 本地化存储。

## 功能清单

- [x] 发布内容：文本输入框，280 字上限，实时字数统计，空内容/超限校验与提示
- [x] 查看时间线：按发布时间倒序展示内容卡片，含头像、昵称、相对时间（刚刚 / x 分钟前 / x 小时前 / 日期）
- [x] 删除内容：单条删除，实时刷新
- [x] Local Storage 持久化：刷新/关闭浏览器后数据不丢失
- [x] 快捷键：Ctrl + Enter 快速发布
- [x] 安全性：对用户输入做 HTML 转义，防止 XSS

## 运行方式

无需构建，任选其一：

1. 直接双击打开 `index.html`；
2. 或启动本地静态服务器（推荐）：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 技术要点

| 项 | 说明 |
| --- | --- |
| 存储 | `localStorage`，键名 `weyan_posts`，JSON 序列化数组 |
| 逻辑 | 原生 DOM 操作 + 事件委托（删除按钮） |
| 样式 | 纯 CSS，卡片式时间线，响应式布局 |

## 目录结构

```
├── index.html   # 页面结构
├── style.css    # 样式
```
